# Pipeline Configuration Manual (`config.toml`)

This document provides explanation for every parameter available in the `config.toml` files used to drive the Single-cell Spatial Transcriptomics Pipeline.

The configuration is split into two files:
1. **Upstream QC Config** 
2. **Downstream Analysis Config**
---

## Global Parameters

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `log_level` | `String` | Sets the logging verbosity. Default is `"INFO"`. Can be set to `"DEBUG"` for troubleshooting or `"WARNING"` to reduce output. |
| `seed` | `Integer` | Global random seed (e.g., `21122023`). Ensures reproducible results across PyTorch, NumPy, Scikit-learn, and Scanpy. |

---

## `[project]`
Defines the core identity and structure of your dataset.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `analysis_name` | `String` | The name of your output folder (e.g., `"tyler_project"`). **Must match** between Upstream QC and Downstream configs to link the data. |
| `slide_name` | `String` | *(QC Config Only)* Name of the specific slide being processed (e.g., `"Slide_1"`). |
| `data_type` | `String` | `"CosMx"` or `"Xenium"`. Dictates coordinate axes (`global` vs `spatial`), QC logic (DAPI vs Nucleus Area), and boundary parsers. |
| `batch_key` | `String` | *(Downstream)* Column name indicating the slide/batch (e.g., `"slide_id"`)|
| `sample_key` | `String` | *(Downstream)* Column name indicating individual tissue samples/ROIs (e.g., `"sample_id"`). Prevents spatial graphs from drawing edges between different tissue slices. |

---

## `[io]`
Manages input data locations.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `base_raw_dir` | `String` | Point to the parent directory containing all your slide folders/runs. |
| `base_zarr_dir` | `String` | Output directory where `spatialdata` Zarr stores will be created (default: `"data_zarrs"`). |
| `dataset_id` | `String` | *(CosMx Only)* The exact prefix of the CosMx flat files (e.g., `"TylerWooldridgeSlide1"`). |
| `dataset_dir` | `String` | Path to the folder containing the raw machine outputs (if not using `base_raw_dir`). |
| `zarr_dir` | `String` | Path where the specific `spatialdata` Zarr store should be created/read from. |
| `entry_point` | `String` | Module number to start the pipeline from (default: `"0"`). |
| `custom_input_adata` | `String` | Path to a preprocessed `.h5ad` if bypassing early modules. |

### `[io.raw_data]` *(Downstream Config Only)*
Maps multiple slides to their respective raw data paths for merging and MuSpAn polygon extraction.
```toml
[io.raw_data]
"Slide_1" = { dataset_dir = "data/tyler_1", zarr_dir = "data/tyler_1.zarr", proseg_zarr_dir = "data/tyler1_proseg.zarr" }
```

## `[pipeline]`
| Parameter | Type | Description |
| :--- | :--- | :--- |
| `modules` | `List[String]` | Tells the script exactly which modules to execute. Modules run sequentially in the order defined here. You can override this using the `--modules` flag in the CLI. |

---

## `[modules.QualityControl]` (Module 1)
Sets filtering thresholds to clean out cellular debris and low-quality data.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `min_counts` | `Integer` | Minimum total transcripts per cell. Cells below this are removed. |
| `min_cells` | `Integer` | Minimum number of cells a gene must be expressed in. Rare/noisy genes are removed. |
| `min_genes` | `Integer` | Minimum unique genes detected per cell. Filters out cells with low transcriptional diversity. |
| `min_area` | `Integer` | Minimum cell area (µm²). Removes small segmentation artifacts. |
| `max_area` | `Integer` | Maximum cell area (µm²). Removes segmentations representing 2+ cells. |
| `min_dapi` | `Integer` | *(Optional)* Minimum DAPI intensity. Removes cells with missing/poor nuclear staining. |
| `fov_metadata_path` | `String` | Path to a CSV mapping FOVs to metadata (e.g., `DiseaseType`, `TreatmentResponse`). Injects these columns into `adata.obs`. |
| `metadata_join_col` | `String` | The exact column name present in both your spatial data and your CSV used to join the metadata together (e.g., "fov" or "slide_id"). |
| `proseg_zarr_path` | `String` | Path to a Zarr store generated by Proseg. Replaces default CosMx segmentations/counts with Proseg-corrected ones. |
| `proseg_cell_id_col` | `String` | Column in the Proseg Zarr identifying the cell ID (default: `"original_cell_id"`). |
| `original_cell_id_col` | `String` | Column in the original Zarr identifying the cell ID (default: `"cell"` or `"index"`). |

## `[modules.MergeData]` (Module 1b)
| Parameter | Type | Description |
| :--- | :--- | :--- |
| `input_files` | `List[String]` | Paths to the `adata.h5ad` files generated by the QC module for each slide. |
| `slide_names` | `List[String]` | Defines the ID for each slide (e.g., `["Slide_1", "Slide_2"]`). Used to make cell barcodes globally unique (e.g., `Slide_1_cell45`). |

## `[modules.DimensionReduction]` (Module 2)
Controls Deep Learning integrations, PCA, UMAP, and Clustering.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `run_pca` | `Boolean` | If `true`, runs standard PCA before clustering. |
| `n_comps` | `Integer` | Number of Principal Components to compute. |
| `use_scviva` | `Boolean` | If `true`, runs the scVIVA spatially-aware VAE pipeline. If `false`, bypasses deep learning models entirely. |
| `scviva_layer` | `String` | The AnnData layer containing *raw integer counts* required by scVI (e.g., `"counts"`). |
| `scviva_spatial_knn` | `Integer` | Number of spatial neighbors used by scVIVA to model the tissue microenvironment graph (default: 10). |
| `scvi_epochs` / `scviva_epochs` | `Integer` | Training epochs for the baseline scVI and spatial scVIVA models. |
| `n_neighbors` | `List[Int]` | Defines KNN sizes for UMAP/Leiden (e.g., `[15, 30]`). The pipeline will iterate and generate outputs for *every* value in this list. |
| `resolution` | `List[Float]` | Defines Leiden clustering resolutions (e.g., `[0.5, 1.0]`). Iterates over every combination of `n_neighbors` and `resolution`. |
| `cluster_name` | `String` | Prefix for the resulting cluster column in `adata.obs` (e.g., `"leiden"` -> `"leiden_n15_r0.5"`). |
| `umap_latent` | `String` | The latent space used to build the UMAP/graph (e.g., `"X_pca"`, `"X_scVI"`, `"X_scVIVA"`, or `"X_scANVI"`). |
| `scviva_batch_size` | `Integer` | Batch size for training scVIVA (default: 512). Lower if running out of GPU memory. |
| `n_latent` | `Integer` | Number of latent dimensions for scVI/scVIVA to learn (default: 30). |
| `n_layers` | `Integer` | Number of hidden layers in the scVI/scVIVA neural network (default: 2). |
| `pre_cluster_res` | `Float` | Leiden resolution used to generate the pre-clustering labels that scVIVA requires (default: 1.0). |
| `dot_size` | `Float` | Size of the dots in the Scanpy UMAP and Spatial scatter plots (default: 5). |

**scANVI / Label Transfer settings (Optional):**
| Parameter | Type | Description |
| :--- | :--- | :--- |
| `use_scanvi` | `Boolean` | If `true`, enables scANVI reference mapping. |
| `scanvi_mode` | `String` | `"scarches"` (fast adapter training) or `"joint"` (de novo joint training with reference). |
| `reference_adata_path` | `String` | Path to the reference dataset `.h5ad` or local scVI model directory. |
| `reference_label_key` | `String` | The column in the reference containing the ground truth cell types. |
| `reference_batch_key` | `String` | The batch column expected by the reference model (maps your data into the model's batch covariate). |
| `scanvi_epochs` | `Integer` | Training epochs for the scANVI model (default: 200). |
| `reference_covariates`| `Dictionary` | *(Optional)* Maps extra categorical covariates (e.g., tissue, assay) required by external pre-trained reference models. |

## `[modules.Annotate]` (Module 3)
Handles automated Cell Type Classification (CellTypist) and Marker-based enrichment (ScType).

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `chosen_cluster` | `String` | The specific clustering column from DR to annotate/analyze (e.g., `"Final_Annotation"` or `"leiden_n15_r0.5"`). |
| `CellTypist_anno` | `Boolean` | Set `true` to run CellTypist. |
| `CellTypist_mode` | `String` | `"one"` runs on `chosen_cluster` only. `"All"` loops through *every* clustering generated in Module 2. |
| `CellTypist_model` | `String` | Pre-trained model to use (e.g., `"Cells_Intestinal_Tract"`). |
| `ScType_anno` | `Boolean` | Set `true` to run ScType. |
| `ScType_tissue` | `String` | Tissue database to use for ScType (e.g., `"Intestine"`). |
| `ScType_custom_db` | `String` | *(Optional)* Path to a custom `.xlsx` ScType marker database. |
| `plot` | `Boolean` | If true (default), generates composition bar charts, UMAPs, and spatial plots for the assigned cell types. |

---

## `[modules.ViewImages]` (Module 4)
Generates high-quality spatial expression plots and ROI grids.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `chosen_cluster` | `String` | The annotation column to color the spatial tissue plot by. |
| `gene_list` | `List[String]` | List of genes to generate spatial expression scatter plots for. |
| `embedding_key` | `String` | Specific embedding to plot (e.g., `"X_umap_n30_X_scANVI"`). |
| `umap_color_columns` | `List[String]` | Metadata columns used to color the UMAP (e.g., `["DiseaseType", "Final_Annotation"]`). |
| `n_grid_x` / `n_grid_y` | `Integer` | *(Xenium Only)* Divides the tissue into an X by Y grid for bounding box generation (Exported for MuSpAn subsetting). |

---

## `[modules.SpatialStat]` (Module 5)
Squidpy spatial topology statistics.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `chosen_cluster` | `String` | The cell type column used to calculate Neighborhood Enrichment, Centrality, and Co-occurrence. |
| `condition_key` | `String` | Metadata column representing biological conditions (e.g., `"TreatmentResponse"`). Aggregates stats across samples sharing a condition. |
| `reference_condition` | `String` | The baseline condition (e.g., `"Healthy"`). Used to generate "Delta" (Δ) difference heatmaps against other conditions. |
| `subsample_fraction` | `Float` | Fraction of cells to use for computationally heavy spatial metrics (co-occurrence, Moran's I). Default is `1.0` (no subsampling). |
| `n_perms_moran` | `Integer` | Number of permutations for Moran's I calculations (default: `100`). |
| `n_jobs` | `Integer` | CPU cores to use. `-1` uses all available cores (default: `-1`). |

---

## `[modules.MuSpan]` (Module 6)
Advanced spatial morphology, cross-PCF, and proximity networks.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `selection_names` | `List[String]` | List of Regions of Interest (ROIs) to process (e.g., `["Whole_Sample"]` or `["stromal_core", "epithelium"]`). |
| `chosen_cluster` | `String` | Cell type annotation column to use. |
| `condition_key` & `reference_condition` | `String` | Same as Module 5; creates aggregated Contact Composition and Morphometric boxplots. |
| `transcripts` | `List[String]` | Specific transcripts to visualize as points overlaid on the cell polygons. |
| `cell_types` | `List[String]` | Selects exactly TWO cell types to compute targeted Cross-Pair Correlation Functions (PCF) for. |
| `max_distance` | `Integer` | Maximum distance threshold (µm) for the Cell-Cell Proximity / Contact Composition network. |
| `network_celltypes` | `List[String]` | List of cell types to specifically highlight in the stacked bar contact composition plots (unlisted types are grouped into "Other"). |
| `[modules.MuSpan.selected_fovs]` | `Dict` | (Sub-table) Maps exactly which FOVs (CosMx) or Box IDs (Xenium) to subset for each sample (e.g., `"Slide_1_Healthy_1" = ["9"]`). |

---

## `[modules.Decoupler]` (Module 7)
Infers Transcription Factor (TF) activities.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `celltype_key` | `String` | The cell type column used to define pseudobulk populations for TF analysis. |
| `organism` | `String` | `"human"`, `"mouse"`, or `"rat"`. Automatically handles gene capitalization mapping. |
| `active_tfs_file_name` | `String` | Name of the output text file storing active TFs (default: `"active_tf.txt"`). |
| `grn` | `String` | The Gene Regulatory Network database to use (`"dorothea"` or `"collectri"`). |
| `dorothea_levels` | `List[String]` | Confidence levels to include from DoRothEA (e.g., `["A", "B"]` limits inference to highly-confident interactions). |

---

## `[modules.Cellphonedb]` (Module 8)
Standard CellPhoneDB microenvironment CCC.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `chosen_cluster` | `String` | The cell type column to analyze interactions between. |
| `microenv_resolution` | `Float` | The Leiden resolution used to spatially cluster the tissue into physical microenvironments before running CPDB (default: `0.5`). |
| `target_sample` | `String` | Target a specific sample to generate the dot/chord plots for. |
| `celltypes` | `List[String]` | Limits visual outputs (dot plots, chord diagrams) to interactions involving these specific cell types. |
| `target_genes` | `List[String]` | Pre-filters the dataset to only analyze specific Ligands/Receptors of interest. |
| `gene_family` | `String or List` | Limits interactions to specific gene families (e.g., chemokines) if specified. |
| `cpdb_version` | `String` | Version of the CellphoneDB database to use (default: `"v5.0.0"`). |
| `human` | `Boolean` | Set `true` if analyzing human tissue (default: `true`). |
| `use_cellsign` | `Boolean` | Enable CellSign integration (default: `false`). |
| `target_microenv` | `List[String]` | Restrict plotting to specific microenvironments (if microenvironment clustering was run). |

## `[modules.LIANA]` (Module 8b)
Continuous Spatial Bivariate CCC via LIANA+.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `bandwidth` | `Integer` | The Gaussian kernel bandwidth used to build the spatial weight matrix (distance decay). |
| `cutoff` | `Float` | The spatial weight cutoff below which neighbor influence drops to zero. |
| `n_nmf_components` | `Integer` | Number of Non-negative Matrix Factorization (NMF) components to extract as spatial signaling programs. |
| `nz_prop` | `Float` | Minimum proportion of non-zero expression required for a ligand/receptor to be considered (default: `0.05`). |
| `resource_name` | `String` | The database resource to use for interactions (default: `"consensus"`). |

---

## `[modules.LIANA_Causal]` (Module 8c)
Condition-specific Causal Networks via Corneto.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `treatment_col` | `String` | Metadata column identifying biological conditions (e.g., `"TreatmentResponse"`). |
| `comparisons` | `List[List[String]]` | Condition pairs to contrast, formatted as `["Test_Condition", "Reference_Condition"]`. |
| `cell_type_pairs` | `List[List[String]]` | The directed cellular cross-talk to model, formatted as `["Source_Cell", "Target_Cell"]`. |
| `solver` | `String` | The optimization solver for Corneto (e.g., `"HIGHS"`, `"SCIPY"`, `"CLARABEL"`). |
| `num_top_receptors` / `num_top_tfs` | `Integer` | Limits the network inference to the top $N$ differentially active Receptors and TFs to prevent combinatorial explosions (default: `10`). |
| `curation_effort` | `Integer` | Minimum citation threshold for OmniPath protein-protein interactions (default: `5`). |
| `expr_prop` | `Float` | Minimum proportion of cells expressing a gene for it to be considered in LIANA+ (default: 0.1 / 10%). |
| `node_cutoff` | `Float` | Weight penalty threshold for pruning nodes in Corneto (default: 0.1). |
| `max_runs` | `Integer` | Maximum optimization runs Corneto attempts to find the most stable causal network (default: 20). |
| `stable_runs` | `Integer` | Number of identical network solutions required to stop early (default: 10). |

---

## `[modules.DEAnalysis]` (Module 9)
Targeted pairwise Pseudobulk Differential Expression.

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `DEAnalysis` | `Boolean` | Enable or disable PyDESeq2 analysis. |
| `celltype_col` | `String` | The cell type column. DE is calculated *within* each cell type. |
| `treatment_col` | `String` | The condition column defining the groups being compared. |
| `comparisons` | `List[List[String]]` | Contrasts to compute, formatted as `["Test_Group", "Reference_Group"]`. (e.g., `["CPIc", "Healthy"]`). Positive LogFC means upregulated in the Test Group. |

## `[modules.WebVisPrep]` (Module 10)
Prepares data for the React frontend (Spatial-VisKit).

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `primary_annotation` | `String` | The main cell type column to load by default in the web application (e.g., `"Final_Annotation"`). |
| `microenv_col` | `String` | Column name defining spatial microenvironments, used for Vitessce hierarchical structural filtering. |
| `annotation_columns` | `List[String]` | List of substrings (e.g., `["leiden", "Broad_Celltype"]`). Any `adata.obs` column containing these substrings will be exported to the frontend dropdowns. |
